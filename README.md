# Desafio 02 - Java Swing Interactive Shapes

Java Swing panel with two selectable and movable shapes.

## Features

- Click a shape to select it and change its color
- Move the selected shape using WASD keys
- Click the background to reset all shapes to their original positions

## Controls

| Key | Action |
|-----|--------|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |
| Mouse click (shape) | Select and change color |
| Mouse click (background) | Deselect and reset positions |

## Shapes

- **Rectangle** — turns red when selected
- **Triangle** — turns yellow when selected

## How to Run

1. Clone the repository
2. Open the project in Eclipse or any Java IDE
3. Run the `main` class inside the `DESAFIO_02` package
